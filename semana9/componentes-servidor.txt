Sistema operativo:
Es el software principal que administra los recursos del computador, como la memoria, el almacenamiento y los procesos. Permite que las aplicaciones y servicios funcionen correctamente.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web del lado del servidor.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas, procesa solicitudes de los usuarios y envía respuestas a los clientes.

Puerto:
Es un número que identifica un punto de comunicación en el servidor. Permite que las aplicaciones reciban y envíen datos a través de la red.

Logs:
Son archivos o registros donde se almacena información sobre la actividad del servidor. Ayudan a monitorear el funcionamiento y a detectar errores o problemas.
